# 🤖 Telegram-бот для удаления ссылок из чата (Vercel Serverless)

Бот отслеживает сообщения в Telegram-чате (группе) и автоматически удаляет любые сообщения, содержащие ссылки (TikTok, Instagram Reels, сайты, скрытые гиперссылки и т.д.), если они отправлены указанным пользователем. Работает бесплатно на Serverless-функциях **Vercel** через вебхуки (24/7, сервер или ПК держать включенным не требуется).

---

## 📋 Пошаговая инструкция по настройке и запуску

### Шаг 1. Создать бота в Telegram
1. Открой в Telegram бота [@BotFather](https://t.me/BotFather) и нажми `/start`.
2. Отправь команду `/newbot`.
3. Введи имя бота и уникальный юзернейм (например, `my_link_moderator_bot`).
4. Скопируй полученный **HTTP API Token** (вида `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`). Он понадобится далее (`BOT_TOKEN`).

> **💡 Как узнать ID пользователя (TARGET_USER_ID):**
> Напиши боту [@userinfobot](https://t.me/userinfobot) или перешли ему сообщение нужного человека, чтобы узнать числовой `Id` (например, `6056988812`).

---

### Шаг 2. Создать репозиторий на GitHub и загрузить код
1. Зайди на [GitHub](https://github.com/) и нажми **New repository** (или `+` в правом верхнем углу).
2. Назови репозиторий, например: `bot-delete-links` (или любое удобное имя).
3. Оставь репозиторий **Public** или **Private** и нажми **Create repository** (галочки README/gitignore ставить не нужно, они уже есть в проекте).
4. Открой терминал в папке проекта и выполни команды (замени `ВАШ_ЛОГИН` и `ИМЯ_РЕПОЗИТОРИЯ` на свои):

```bash
git add .
git commit -m "Initial commit: telegram link remover bot"
git remote add origin https://github.com/ВАШ_ЛОГИН/bot-delete-links.git
git push -u origin main
```

---

### Шаг 3. Загрузить проект на Vercel
1. Перейди на [Vercel](https://vercel.com/) и войди через свой GitHub-аккаунт.
2. Нажми кнопку **"Add New..."** → **"Project"**.
3. Найди в списке созданный репозиторий (например, `bot-delete-links`) и нажми **Import**.
4. В блоке **Environment Variables** (Переменные окружения) добавь 3 переменные:
   - `BOT_TOKEN` — токен от BotFather (например: `123456789:ABC...`).
   - `TARGET_USER_ID` — ID пользователя, чьи ссылки надо удалять (например: `6056988812`).
   - `VERCEL_PROJECT_URL` — адрес твоего проекта на Vercel (можно указать пока пример `https://my-bot.vercel.app`, а после деплоя обновить точным доменом из Vercel).
5. Нажми **Deploy**.

---

### Шаг 4. Установить правильный VERCEL_PROJECT_URL и активировать Webhook
1. После завершения деплоя Vercel выдаст тебе адрес домена проекта (например, `https://bot-delete-links.vercel.app`).
2. Зайди в настройки проекта: **Settings** → **Environment Variables**:
   - Убедись, что значение `VERCEL_PROJECT_URL` совпадает с твоим реальным адресом (например, `https://bot-delete-links.vercel.app`).
   - Если изменил переменную, сделай быстрый Redeploy (**Deployments** → три точки у последнего деплоя → **Redeploy**).
3. Перейди в браузере по ссылке активации вебхука:
   ```text
   https://ТВОЙ-ДОМЕН.vercel.app/api/setup
   ```
4. В окне браузера должен появиться ответ:
   ```json
   {
     "ok": true,
     "result": true,
     "description": "Webhook was set",
     "webhook_url": "https://ТВОЙ-ДОМЕН.vercel.app/api/telegram"
   }
   ```
   *(Если `"ok": true` — Telegram успешно привязан к твоему Vercel).*

---

### Шаг 5. Добавить бота в группу Telegram
1. Добавь созданного бота в нужный Telegram-чат / группу.
2. Сделай бота **Администратором** чата.
3. Обязательно выдай право:
   - ✅ **Удаление сообщений (Delete messages)**.
4. *(Опционально)* Отключи в @BotFather режим приватности (`/setprivacy` → `Disable`), чтобы бот видел все входящие текстовые сообщения в группах.

---

## 🛠 Проверка работы
- Отправь в группу любое текстовое сообщение со ссылкой (например: `https://google.com`, `tiktok.com/...`, `instagram.com/reel/...`) от имени целевого пользователя (`TARGET_USER_ID`).
- Бот моментально удалит это сообщение из чата.

---

## 🔒 Безопасность
- Файл `.env` добавлен в `.gitignore` и **не попадет** в публичный GitHub-репозиторий.
- Все токены хранятся исключительно в зашифрованных переменных Vercel.
