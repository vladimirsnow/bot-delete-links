# 🤖 Telegram Media Downloader & Link Moderator (Vercel Serverless)

Telegram-бот для группы с двумя режимами работы:
1. **🎬 Автоскачивание медиа (для всех обычных участников):**
   - При отправке ссылки на **TikTok**, **Instagram Reels / Posts** или **YouTube Shorts**, бот автоматически скачивает видео (или альбом фото) и присылает его в чат **ответом (реплаем)** на сообщение с ссылкой, **без лишних подписей**.
2. **🚫 Исключение для Таргет-пользователя (`TARGET_USER_ID`):**
   - Если сообщение отправлено указанным пользователем и содержит любую ссылку, бот моментально **удаляет** его сообщение из чата (без скачивания).

Работает бесплатно на Serverless-функциях **Vercel** через вебхуки (24/7).

---

## 📋 Пошаговая инструкция по настройке и запуску

### Шаг 1. Создать бота в Telegram
1. Открой [@BotFather](https://t.me/BotFather) и нажми `/start`.
2. Отправь команду `/newbot`, придумай имя и юзернейм бота.
3. Скопируй полученный **HTTP API Token** (`BOT_TOKEN`).

---

### Шаг 2. Загрузить код на GitHub
В папке проекта в терминале выполни:

```bash
git add .
git commit -m "feat: download and send tiktok/reels/shorts in reply without caption"
git push
```

*(Если репозиторий еще не привязан к GitHub, сначала выполни `git remote add origin https://github.com/ВАШ_ЛОГИН/bot-delete-links.git` и `git push -u origin main`)*.

---

### Шаг 3. Настройка переменных на Vercel
В панели **Vercel** → твой проект → **Settings** → **Environment Variables** укажи:
- `BOT_TOKEN` — токен от @BotFather.
- `TARGET_USER_ID` — цифровой ID пользователя, чьи ссылки надо удалять (например: `6056988812`).
- `VERCEL_PROJECT_URL` — адрес проекта на Vercel (например: `https://bot-delete-links.vercel.app`).
- *(Опционально)* `COBALT_API_URL` — персональный адрес инстанса Cobalt, если хочешь использовать собственный сервер для скачивания.

После изменения переменных сделай **Redeploy**.

---

### Шаг 4. Активация Webhook
После деплоя открой в браузере:
```text
https://ТВОЙ-ДОМЕН.vercel.app/api/setup
```
Должен вернуться ответ `{"ok": true, "result": true, ...}`.

---

### Шаг 5. Настройка бота в группе Telegram
1. Добавь бота в свою группу и выдай ему права **Администратора**.
2. Обязательно включи право:
   - ✅ **Удаление сообщений (Delete messages)**.
3. В [@BotFather](https://t.me/BotFather) отправь команду `/setprivacy`, выбери бота и нажми **Disable** (это позволит боту видеть ссылки в сообщениях участников группы).
